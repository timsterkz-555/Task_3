# Результаты UI-тестов Stellar Burgers

Проверка выполнена 29 октября 2026 года в ветке `develop3` на macOS 15.8.1 arm64.
Maven 3.9.16 и тестовая JVM используют Amazon Corretto **11.0.31**. Версия JVM записана в каждом результате Allure.
Оба браузера запускались с обычным окном, без `headless`.

| Вход | 4/4 | 4/4 |
| Личный кабинет и возврат в конструктор | 3/3 | 3/3 |
| Выход | 1/1 | 1/1 |

| **Всего успешно** | **13/13** | **13/13** |

В каждом прогоне Allure подтверждает 9 успешных удалений пользователей через API и 13 закрытий браузера. Тест с коротким паролем не создал пользователя. Пользователи для трёх тестов разделов не требуются.

Проверенные приложения и драйверы:

- Google Chrome **156.0.8078.48**, ChromeDriver **156.0.8078.73**.
- Яндекс.Браузер **26.10.0.1852**, Chromium capability **152.0.7977.1852**; официальный YandexDriver **26.10.0.1855**, Chromium **152.0.7977.140**. Запущено приложение `/Applications/Yandex.app`.

## Отчёты для pull request

- [Allure: Chrome](allure-chrome/index.html).
- [Allure: Яндекс.Браузер](allure-yandex/index.html).
- [Исходные результаты обоих прогонов](allure-results.zip).

Каждый HTML содержит свои данные, JavaScript и стили. Скачайте `index.html` из GitHub и откройте его в браузере. Из корня локального проекта:

```bash
open reports/allure-chrome/index.html
open reports/allure-yandex/index.html
```

Отчёты фактически созданы через `mvn allure:report -Dbrowser=chrome` и `mvn allure:report -Dbrowser=yandex`. Встроенные JSON проверены: в каждом HTML ровно 13 тестов со статусом `passed`, а также параметры браузера и окружения. Исходные результаты сохранены раздельно в архиве (`chrome/`, `yandex/`) и в `target/allure-results/`.

## Ограничения и замечания

- Ошибок приложения в этих 13 сценариях не обнаружено; тесты не отключались, проверки не ослаблялись.
- На сайте кнопка завершения сессии называется «Выход», поэтому локатор использует эту фактическую подпись.
- Selenium сообщает, что для Chrome 156 нет точного соответствия CDP (ближайшая версия 153). Тесты работают через обычный WebDriver и не используют CDP; все сценарии прошли. Также выводится предупреждение SLF4J об отсутствии провайдера логирования.
- Визуальная проверка HTML через инструмент управления браузером не выполнена: его политика запрещает открывать `file://`. Файлы и встроенные результаты проверены локально без исполнения HTML.

Для отправки используйте команды из основного [README](../README.md). Добавьте в PR папку `reports` вместе с кодом; `target` и вспомогательные файлы Maven Site исключены из Git.
